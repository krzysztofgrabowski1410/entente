# Visualization API

Two renderers over one geometry: a stdlib SVG board renderer (works in the
default environment) and a Pillow GIF rasterizer (`viz` group). Map geometry is data (`"centroids"` in the map
JSON, integrity-tested); only the standard map ships it today.

## SVG (stdlib)

```python
# entente.viz.svg
def build_board_scene(graph, state, ownership, *, caption="", orders=(),
                      dislodgements=()) -> Scene: ...
def render_board(graph, state, ownership, *, size=720, **scene_kwargs) -> str: ...
def build_record_scene(graph, record) -> Scene: ...
def render_record(graph, record, *, size=720) -> str: ...
def scene_to_svg(scene: Scene, *, size: int = 720) -> str: ...
def load_centroids(map_name: str) -> dict[str, tuple[float, float]]: ...
def power_colors(powers: Sequence[str]) -> dict[str, str]: ...
```

### Minimal working example

```python
from entente.engine.game import Game
from entente.viz.svg import render_board

game = Game.new("standard", "standard")
svg = render_board(game.graph, game.state, game.ownership, caption="S1901M")
open("board.svg", "w").write(svg)
```

## GIF (`viz` group, Pillow)

```python
# entente.viz.gif
def scene_to_image(scene, *, size=720, supersample=2) -> Image.Image: ...
def game_frames(game: Game, *, size=720) -> list[Image.Image]: ...
def write_gif(frames, path, *, duration_ms=...) -> Path: ...
```

`game_frames` renders one frame per phase (plus start/result bookends);
`write_gif` encodes them byte-identically for a given seed (determinism is
pinned by `tests/viz/test_gif.py`). The committed README demo is regenerated by
`scripts/make_demo_gif.py`.
